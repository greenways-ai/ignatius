# Agent workflows

An agent workflow begins with a work definition pinned to exact inputs and dependencies. An eligible agent claims and starts the work, records bounded checkpoints, registers exact output resources, and submits completion through an ordinary signed transaction.

Schedulers may derive ready, blocked, and running views, but those projections do not become authority. Completion is authoritative only after chain commitment.
