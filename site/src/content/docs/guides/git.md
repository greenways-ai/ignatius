# Git integration

The Git adapter verifies provider inputs and emits unsigned canonical payloads describing repositories, commits, issues, pull requests, reviews, and delivery evidence. The ordinary Ignatius client then presents the exact payload to the authorised signer.

Provider identity is not automatically an Ignatius account, and a mutable GitHub conversation is not a canonical chain decision.
