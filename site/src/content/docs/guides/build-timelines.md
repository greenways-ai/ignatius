# Build timelines

Build work records exact input roots, tool and environment evidence, ordered steps, checkpoints, output artefacts, and attestations. Large payloads remain in Git or object storage while canonical records retain their immutable references.

This yields a deterministic history of what was requested, what ran, what it consumed, what it produced, and which signed decision accepted it.
