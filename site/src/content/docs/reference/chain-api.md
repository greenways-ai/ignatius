# Chain API

The portable Ignatius client prepares explicit `postgres.core` capability requests and validates their exact results. Credentials, handles, SQL implementation details, and database paths never enter portable values.

The generated contracts and SQL under `db/` remain the authoritative interface inventory. Consult the repository release contract before integrating against development-only functions.
