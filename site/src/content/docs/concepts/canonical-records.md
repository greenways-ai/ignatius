# Canonical records

Ignatius records processes, artefacts, work definitions, checkpoints, reviews, attestations, evidence, proposals, accepted heads, and releases as immutable canonical values connected by labelled content-addressed edges.

Stable logical resource IDs select exact immutable versions. A Git parent is not automatically the previously selected Ignatius version; selection is an explicit signed chain decision.
