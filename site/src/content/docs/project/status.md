# Status and roadmap

## Implemented foundation

Canonical records, signed sequencing, transaction admission, deterministic execution, linear blocks and receipts, provider-neutral immutable storage, workflow reducers, agent claims and checkpoints, workspace proposals and reviews, policy-gated main acceptance, releases, and a Git adapter.

## Release work

The stable chain API, dependency extraction, production provider composition, and data-preserving consumer migrations remain active work. Follow [issue 76 ↗](https://github.com/greenways-ai/ignatius/issues/76) for the release contract.
